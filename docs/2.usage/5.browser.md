`@nodecfdi/credentials` incluye una compilación **IIFE** (`dist/index.iife.js`) lista para cargarse directamente en el navegador mediante una etiqueta `<script>`, sin necesidad de un empaquetador.

Este archivo ya empaqueta internamente `node-forge` y `@nodecfdi/base-converter`, y expone todas las clases principales bajo la variable global **`ncfdiCredentials`** (`window.ncfdiCredentials`).

::note
La dependencia par **`luxon`** es externa al bundle IIFE, por lo que debes cargar el script global de `luxon` **antes** de cargar `index.iife.js`.
::

## Carga mediante `<script>` (CDN o archivo local)

Puedes incluir `luxon` y `@nodecfdi/credentials` desde una CDN como **unpkg** o **jsDelivr** (o sirviendo `node_modules/@nodecfdi/credentials/dist/index.iife.js`):

::code-group
```html [unpkg]
<!-- 1. Cargar Luxon (expone la variable global `luxon`) -->
<script src="https://unpkg.com/luxon@3/build/global/luxon.min.js"></script>

<!-- 2. Cargar @nodecfdi/credentials IIFE (expone `ncfdiCredentials`) -->
<script src="https://unpkg.com/@nodecfdi/credentials/dist/index.iife.js"></script>
```

```html [jsDelivr]
<!-- 1. Cargar Luxon (expone la variable global `luxon`) -->
<script src="https://cdn.jsdelivr.net/npm/luxon@3/build/global/luxon.min.js"></script>

<!-- 2. Cargar @nodecfdi/credentials IIFE (expone `ncfdiCredentials`) -->
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/credentials/dist/index.iife.js"></script>
```
::

Una vez cargados los scripts, tienes disponibles todas las clases en `globalThis.ncfdiCredentials` (o directamente `ncfdiCredentials`):

```js
const {
  Certificate,
  Credential,
  PemExtractor,
  PfxExporter,
  PfxReader,
  PrivateKey,
  PublicKey,
  SerialNumber,
} = globalThis.ncfdiCredentials;
```

## Ejemplo completo en HTML con IIFE

Los constructores de `@nodecfdi/credentials` reciben el contenido de los archivos `.cer`, `.key` o `.pfx` como una **cadena binaria** (*binary string*) o texto PEM.

A continuación se muestra una página HTML completa que lee los archivos `.cer` y `.key` seleccionados por el usuario en un `<input type="file">`, valida la credencial, muestra sus datos fiscales y genera un sello digital en Base64 usando `ncfdiCredentials`:

```html [index.html]
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Ejemplo @nodecfdi/credentials (IIFE)</title>
    <script src="https://unpkg.com/luxon@3/build/global/luxon.min.js"></script>
    <script src="https://unpkg.com/@nodecfdi/credentials/dist/index.iife.js"></script>
  </head>
  <body>
    <form id="credential-form">
      <div>
        <label>Certificado (.cer): <input type="file" id="cer-file" accept=".cer,.pem" required /></label>
      </div>
      <div>
        <label>Llave privada (.key): <input type="file" id="key-file" accept=".key,.pem" required /></label>
      </div>
      <div>
        <label>Contraseña: <input type="password" id="password" required /></label>
      </div>
      <div>
        <label>Cadena a firmar: <input type="text" id="data" value="||4.0|cadena-original||" required /></label>
      </div>
      <button type="submit">Procesar y firmar</button>
    </form>

    <pre id="output"></pre>

    <script>
      const { Credential } = globalThis.ncfdiCredentials;

      // Convierte un objeto File del navegador a cadena binaria (binary string)
      async function fileToBinaryString(file) {
        const buffer = await file.arrayBuffer();
        const bytes = new Uint8Array(buffer);
        let binary = '';
        for (const byte of bytes) {
          binary += String.fromCodePoint(byte);
        }

        return binary;
      }

      document.querySelector('#credential-form').addEventListener('submit', async (event) => {
        event.preventDefault();
        const output = document.querySelector('#output');

        try {
          const cerFile = document.querySelector('#cer-file').files[0];
          const keyFile = document.querySelector('#key-file').files[0];
          const password = document.querySelector('#password').value;
          const dataToSign = document.querySelector('#data').value;

          const [cerContents, keyContents] = await Promise.all([
            fileToBinaryString(cerFile),
            fileToBinaryString(keyFile),
          ]);

          // Crear la credencial y validar que el .cer y .key sean pareja
          const credential = Credential.create(cerContents, keyContents, password);

          // Firmar datos y convertir la firma binaria a Base64 con btoa()
          const signatureBinary = credential.sign(dataToSign, 'sha256');
          const signatureBase64 = btoa(signatureBinary);

          output.textContent = JSON.stringify(
            {
              rfc: credential.rfc(),
              legalName: credential.legalName(),
              serialNumber: credential.certificate().serialNumber().bytes(),
              type: credential.isCsd() ? 'CSD' : 'FIEL',
              validOnNow: credential.certificate().validOn(),
              signatureBase64,
              verified: credential.verify(dataToSign, signatureBinary, 'sha256'),
            },
            null,
            2,
          );
        } catch (error) {
          output.textContent = `Error: ${error.message}`;
        }
      });
    </script>
  </body>
</html>
```

::tip
Si utilizas un empaquetador moderno (como Vite, Nuxt o Webpack), también puedes importar las clases con sintaxis ESM directamente desde `@nodecfdi/credentials` y reutilizar la misma función `fileToBinaryString(file)`.
::
