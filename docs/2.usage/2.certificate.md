La clase `Certificate` permite cargar y analizar certificados X.509 emitidos por el SAT (tanto CSD como eFirma/FIEL). Soporta automáticamente tres formatos de entrada:

- **X.509 DER binario** (el archivo `.cer` tal como lo descarga el contribuyente del SAT).
- **X.509 PEM** (con encabezados `-----BEGIN CERTIFICATE-----`).
- **X.509 DER codificado en Base64** (el contenido del atributo `Certificado` de un CFDI XML).

## Carga de un certificado

::code-group
```ts [Desde archivo (Node.js)]
import { openCertificateFile } from '@nodecfdi/credentials/node';

const certificate = openCertificateFile('/ruta/al/certificado.cer');
```

```ts [Desde contenido en memoria]
import { Certificate } from '@nodecfdi/credentials';

// Puede ser cadena binaria DER, texto PEM o cadena Base64
const certificate = new Certificate(certificateContents);
```
::

## Datos del contribuyente y tipo de certificado

`Certificate` decodifica adecuadamente atributos en UTF-8 del `subject` y del `issuer`:

```ts [certificate-subject.ts]
console.log(certificate.rfc()); // "AAA010101AAA"
console.log(certificate.legalName()); // "ACCEM SERVICIOS EMPRESARIALES SC"
console.log(certificate.branchName()); // Nombre de sucursal/unidad (OU) o "" si es FIEL
console.log(certificate.name()); // "/CN=..."

// Identificar si es FIEL o CSD
console.log(certificate.satType().isFiel()); // boolean
console.log(certificate.satType().isCsd()); // boolean
```

::note
El SAT distingue un CSD de una eFirma (FIEL) a través del atributo `OU` (*Organizational Unit* / `branchName`): los certificados de **FIEL** tienen `branchName() === ''`, mientras que los **CSD** incluyen el nombre de la unidad o sucursal.
::

## Vigencia del certificado

Puedes consultar el rango de validez del certificado como objetos nativos `Date` de JavaScript, como instancias `DateTime` de **Luxon**, o verificar si es válido en una fecha determinada:

```ts [certificate-validity.ts]
import { DateTime } from 'luxon';

// Objetos Date nativos
const fromDate: Date = certificate.validFrom();
const toDate: Date = certificate.validTo();

// Objetos DateTime de Luxon
const fromLuxon: DateTime = certificate.validFromDateTime();
const toLuxon: DateTime = certificate.validToDateTime();

// Verificar si el certificado está vigente en este instante (DateTime.now())
console.log('¿Vigente ahora?:', certificate.validOn());

// Verificar vigencia en una fecha específica
const customDate = DateTime.fromISO('2026-06-15T12:00:00Z');
console.log('¿Vigente en fecha?:', certificate.validOn(customDate));
```

## Número de serie

El método `serialNumber()` devuelve una instancia de [`SerialNumber`](/packages/credentials/api-reference/exports-and-types). En los certificados del SAT, el número de serie de 20 dígitos que se coloca en el atributo `NoCertificado` del CFDI corresponde a la representación ASCII (`bytes()`) del número de serie hexadecimal:

```ts [certificate-serial.ts]
const serial = certificate.serialNumber();

console.log(serial.bytes()); // "30001000000500003416" (NoCertificado de 20 dígitos)
console.log(serial.hexadecimal()); // "3330303031303030303030353030303033343136"
console.log(serial.decimal()); // "292233162870206001759766198425879490508935869462"
```

## Formato PEM y datos de X.509

Cuando necesitas insertar el certificado en un XML (por ejemplo, en el atributo `Certificado` de un CFDI o en un nodo `<ds:X509Certificate>`) o consultar datos del emisor:

```ts [certificate-pem-issuer.ts]
// Contenido PEM completo (con encabezados -----BEGIN CERTIFICATE-----)
const pem = certificate.pem();

// Contenido PEM en una sola línea sin encabezados (ideal para atributo Certificado en CFDI)
const oneLine = certificate.pemAsOneLine();

// Cadena del emisor formateada conforme al estándar RFC 4514 (útil para XML-DSig / XAdES)
const issuerRfc4514 = certificate.issuerAsRfc4514();

// Llave pública asociada al certificado
const publicKey = certificate.publicKey();
```

### Otros métodos de inspección X.509

| Método | Retorno | Descripción |
| --- | --- | --- |
| `version()` | `string` | Versión del certificado X.509. |
| `hash()` | `string` | Hash del emisor (`issuer.hash`). |
| `signatureTypeLN()` | `string` | Identificador de la firma del certificado. |
| `subject()` | `forge.pki.Certificate['subject']` | Objeto `subject` completo de `node-forge`. |
| `subjectData(key)` | `forge.pki.CertificateField \| undefined` | Busca un campo del `subject` por nombre corto (`'CN'`, `'OU'`) u opciones `{ type: '2.5.4.45' }`. |
| `issuer()` | `forge.pki.Certificate['issuer']` | Objeto `issuer` completo de `node-forge`. |
| `issuerData(key)` | `forge.pki.CertificateField` | Busca un campo del `issuer` por nombre corto u OID. |
| `validity()` | `{ notBefore: Date, notAfter: Date }` | Objeto crudo de validez del certificado. |
| `extensions()` | `Record<string, unknown>[]` | Arreglo de extensiones X.509 del certificado. |
| `parsed()` | `Record<string, unknown>` | Estructura interna con todos los campos extraídos. |
| `Certificate.convertDerToPem(contents)` | `string` | Método estático que convierte contenido DER binario o DER Base64 a formato PEM. |
