El formato **PFX (PKCS#12)** permite empaquetar en un solo archivo cifrado tanto el certificado X.509 como su llave privada. `@nodecfdi/credentials` incluye `PfxReader` para leer archivos PFX y `PfxExporter` para generarlos a partir de un [`Credential`](/packages/credentials/usage/credential).

## Leer un archivo PFX (`PfxReader`)

### Desde archivo local en Node.js (`readPfxFile`)

Usa `readPfxFile` desde `@nodecfdi/credentials/node` para obtener directamente una instancia de `Credential`:

```ts [read-pfx-node.ts]
import { readPfxFile } from '@nodecfdi/credentials/node';

const credential = readPfxFile('/ruta/al/archivo.pfx', 'contraseña-del-pfx');

console.log(credential.rfc());
console.log(credential.legalName());
```

### Desde contenido en memoria (`PfxReader`)

Si tienes los bytes del archivo PFX como cadena binaria (por ejemplo, en el navegador o descargado de un almacenamiento remoto), utiliza `PfxReader.createCredentialFromContents`:

```ts [read-pfx-memory.ts]
import { PfxReader } from '@nodecfdi/credentials';

const credential = PfxReader.createCredentialFromContents(pfxBinaryContents, 'contraseña-del-pfx');
```

::tip
Si necesitas acceder directamente a los objetos `forge.pki.Certificate` y `forge.pki.PrivateKey` de `node-forge`, puedes llamar a `PfxReader.loadPkcs12(pfxBinaryContents, 'contraseña-del-pfx')`.
::

## Exportar a formato PFX (`PfxExporter`)

### Guardar directamente en un archivo en Node.js (`exportPfxToFile`)

La función `exportPfxToFile` de `@nodecfdi/credentials/node` recibe una instancia de `Credential` (o `PfxExporter`), la ruta de salida, la contraseña para proteger el PFX y opcionalmente el algoritmo de cifrado:

```ts [export-pfx-node.ts]
import { exportPfxToFile, openCredentialFiles } from '@nodecfdi/credentials/node';

const credential = openCredentialFiles(
  '/ruta/al/certificado.cer',
  '/ruta/a/la/llave.key',
  'contraseña-llave',
);

// Exportar el PFX a disco (opcionalmente especificando 'aes256', 'aes192', 'aes128' o '3des')
exportPfxToFile(credential, '/ruta/salida/credencial.pfx', 'contraseña-pfx', 'aes256');
```

### Exportar en memoria o Base64 (`PfxExporter`)

La clase `PfxExporter` funciona tanto en Node.js como en navegadores y permite exportar el PFX como cadena binaria DER o directamente en Base64:

```ts [export-pfx-memory.ts]
import { PfxExporter } from '@nodecfdi/credentials';

const exporter = new PfxExporter(credential);

// Obtener como cadena binaria DER (PKCS#12)
const pfxBinary = exporter.export('contraseña-pfx', 'aes256');

// Obtener codificado en Base64 (útil para almacenar o enviar por JSON/API)
const pfxBase64 = exporter.exportToBase64('contraseña-pfx', 'aes256');
```

### Algoritmos PFX soportados (`AlgorithmPfx`)

El parámetro opcional `algorithm` en `export()`, `exportToBase64()` y `exportPfxToFile()` acepta los siguientes valores:

- `'aes128'`
- `'aes192'`
- `'aes256'`
- `'3des'` *(útil cuando se requiere compatibilidad con sistemas legacy)*
